# HOOD
### A Cross-Platform Gaming Ecosystem

**HOOD** is an evolving gaming platform built around immersive driving experiences, interconnected virtual environments and the long-term vision of cross-platform gaming.

What begins as a neighbourhood driving experience is being developed into something much bigger: a connected gaming ecosystem where players, vehicles, environments and experiences can eventually interact across different games and platforms.

HOOD is part of the **Anemoia** project, developed under Nova Trix Media.

---

## The Vision

The ultimate objective is to build a cross-platform gaming ecosystem.

Rather than developing isolated games that operate independently, HOOD is being built towards an interconnected architecture in which different gaming experiences can share elements of a common world.

The long-term vision includes:

- **Cross-platform gameplay:** Connecting players across desktop, mobile and future gaming platforms.
- **Cross-game interaction:** Enabling players and experiences from different games to interact within a connected ecosystem.
- **Shared environments:** Building interconnected virtual spaces that can evolve independently while remaining part of a wider world.
- **Persistent player identity:** Developing player profiles, progression and experiences that can eventually extend across supported games.
- **Connected multiplayer experiences:** Introducing shared sessions, competitive challenges and real-time player interaction.
- **Expandable game architecture:** Making it possible to introduce new games and experiences without rebuilding the entire ecosystem.

Cross-platform gaming is the destination. HOOD's driving experience is the foundation.

---

## What We Are Building Now

The first implementation is a browser-based 3D driving game inspired by real-world Nairobi environments and automotive culture.

The experience focuses on:

- Vehicle-based exploration.
- Recognisable urban driving environments.
- Route-based challenges and racing.
- Immersive cockpit experiences.
- Responsive desktop and mobile controls.
- A foundation for future multiplayer and connected gameplay.

The initial environments and routes provide a starting point for a larger virtual world.

---

## Current Features

The current development baseline includes:

- 3D vehicle driving using Three.js.
- Vehicle selection.
- Route selection before entering gameplay.
- Free Drive and Race game modes.
- State House Avenue driving route.
- Ngara Sprint challenge.
- Desktop keyboard controls.
- Mobile touch controls and landscape gameplay support.
- Co-Driver cockpit view.
- In-game vehicle lighting controls.
- HOOD Radio integration.
- Sprint distance tracking.
- Driving HUD and route information.
- Vehicle models and supporting 3D assets.

Features and availability may vary between individual releases.

## Technology

The project currently uses:

- **Three.js** – 3D rendering and game environments.
- **JavaScript ES Modules** – Gameplay and application logic.
- **WebGL** – Browser-based graphics rendering.
- **GLTF / GLB** – 3D vehicle and environment assets.
- **HTML, CSS and JavaScript** – User interface and controls.
- **PHP** – Supporting server-side functionality where required.

The architecture is being developed incrementally, with an emphasis on modularity and future expansion.

## Repository Structure

The repository is organised to support modular development and versioned releases.

Individual release folders preserve the state of each published edition.

```text
Hood/
├── README.md
├── .gitignore
├── release-notes/
├── v1.2.1/
├── v1.2.2/
├── v1.2.3/
├── v1.2.4/
├── v1.2.5/
└── ...
```

The actual project structure and supporting directories are maintained within each release.

### Release Strategy

The project follows a versioned release approach.

- `release/v1.2` – Development and maintenance branch for v1.2.x.
- `v1.2.5` – Current baseline edition.
- Future releases introduce incremental improvements while preserving earlier versions.

Major architectural changes will be introduced through subsequent release cycles.
