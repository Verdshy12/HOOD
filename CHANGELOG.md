# HOOD — Changelog

## v1.0.1 — 2 November 2026

### Added
- Career Mode with player profiles, progression and vehicle unlocks.
- Circuit Mode with three-lap and five-lap race events.
- Circuit lap timing, best-lap tracking and race results.
- Sprint Mode with checkpoint progression and personal-best records.
- Free Drive for open-ended route exploration.
- Vehicle-specific physics profiles for supported cars.
- Expanded vehicle catalogue: Subaru WRX STI, Dodge, GTR-35 and Nissan Skyline R34.
- Career and race-record persistence.
- Improved mobile input handling and steering control.
- Additional circuit route-generation and validation tools.

### Improved
- Vehicle model rigging and wheel assembly handling.
- Vehicle physics configuration and driving behaviour.
- Route catalogue and circuit validation.
- Gameplay HUD and race-state handling.
- Persistence and input test coverage.

### Testing
- Automated test suite passed during release preparation.
- Vehicle, world, route, sprint, circuit, career, persistence,
  input and model-rigging tests included.

### Release baseline
- v1.0.0 remains the original GitHub baseline.
- v1.0.1 is the subsequent development release.
